# Blazor + ASP.NET Core prototype

## Intended request path

Browser → Blazor components → ASP.NET Core services/API → Entity Framework Core → data provider

## Initial learning slice

1. Display a service-ticket list.
2. Add a ticket form.
3. Persist tickets through EF Core.
4. Add technician assignment.
5. Add scheduling and conflict validation.
6. Evaluate reusable Razor components for a future MAUI Blazor Hybrid client.

The repository intentionally contains no ticket implementation yet. SQL, SharePoint, and Dataverse experiments should be isolated behind a repository abstraction.
