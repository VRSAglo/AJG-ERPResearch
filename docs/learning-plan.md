# Learning plan

1. State the concept being learned.
2. Add the smallest working change.
3. Run it locally.
4. Explain what each file contributes.
5. Record strengths, weaknesses, and questions.
6. Commit the completed learning step.

Suggested sequence: Razor components → forms and validation → dependency injection → domain services → EF Core → SQL Server → scheduling → optional MAUI shared-UI experiment.
