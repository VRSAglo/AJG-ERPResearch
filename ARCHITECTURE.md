# Next.js + Spring Boot prototype

## Intended request path

Browser → Next.js/React → REST/JSON → Spring Boot → JPA/Hibernate → SQL

## Initial learning slice

1. Display a service-ticket list.
2. Add a ticket form.
3. Persist tickets through the API.
4. Add technician assignment.
5. Add scheduling and conflict validation.
6. Display scheduled work in FullCalendar.

The repository intentionally contains no ticket implementation yet. Each layer should be added and committed separately while learning it.
